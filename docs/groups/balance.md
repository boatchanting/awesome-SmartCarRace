# 平衡组

平衡组需要同时解决姿态稳定、路径跟踪和速度控制问题，对机械结构、IMU 数据质量和控制周期稳定性要求较高。

## 核心能力

- 姿态估计。
- 平衡控制。
- 速度控制。
- 路径跟踪。
- 机械重心和结构刚性优化。

## 常见硬件

- IMU。
- 编码器。
- 主控板。
- 电机与驱动。
- 电池与电源管理。
- 车体结构件。

## 常见软件模块

- IMU 采样与滤波。
- 姿态解算。
- 直立环、速度环和方向环。
- 状态机。
- 异常保护。
- 参数管理。

## 关键难点

- IMU 零偏和振动噪声。
- 控制周期抖动。
- 多环参数耦合。
- 起步、停车和跌倒保护。
- 机械改动对控制参数影响明显。
