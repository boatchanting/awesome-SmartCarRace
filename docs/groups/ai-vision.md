# AI 视觉组

AI 视觉组通常涉及图像采集、模型训练、推理部署和实时控制，需要同时关注算法效果与嵌入式算力约束。

## 核心能力

- 数据采集与标注。
- 模型训练与评估。
- 嵌入式推理部署。
- 目标或赛道状态识别。
- 推理结果与控制策略融合。

## 常见硬件

- 摄像头。
- 主控或边缘计算模块。
- 电机与驱动。
- 舵机。
- 存储与调试接口。
- 稳定供电模块。

## 常见软件模块

- 图像采集。
- 数据集管理。
- 模型训练脚本。
- 推理运行时。
- 后处理。
- 控制状态机。
- 日志和回放工具。

## 关键难点

- 数据集覆盖不足。
- 训练效果和实车效果不一致。
- 推理延迟过高。
- 光照和场地差异导致泛化问题。
- 模型输出与控制策略衔接不稳。
