# 摄像头组

摄像头组通常以图像作为主要赛道感知来源，需要处理采集、图像预处理、路径提取、元素识别和控制输出之间的实时链路。

## 核心能力

- 图像采集与曝光控制。
- 赛道边线、中心线或目标区域提取。
- 特殊元素识别。
- 路径可信度判断。
- 速度与方向控制。

## 常见硬件

- 主控板。
- 摄像头模块。
- 电机与驱动。
- 舵机。
- 编码器。
- 调试串口或无线模块。

## 常见软件模块

- 摄像头驱动。
- 图像预处理。
- 边线和中心线提取。
- 元素识别状态机。
- 速度规划。
- 舵机控制。
- 日志与参数管理。

## 关键难点

- 光照变化导致阈值不稳定。
- 图像延迟影响高速控制。
- 特殊元素误识别。
- 近端和远端路径权重分配。
- 调试数据不易回放。
