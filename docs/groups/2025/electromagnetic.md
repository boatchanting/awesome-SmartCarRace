# 电磁组

电磁组通常通过电感阵列感知赛道电磁信号，重点在于信号采集、抗干扰、路径估计和高速稳定控制。

## 核心能力

- 电感信号采集。
- 模拟前端调理。
- 信号滤波和归一化。
- 赛道偏差估计。
- 电机干扰抑制。

## 常见硬件

- 电感阵列。
- 运放与滤波电路。
- ADC 采样模块。
- 主控板。
- 电机、电调或驱动模块。
- 编码器。

## 常见软件模块

- ADC 采样。
- 信号滤波。
- 偏差计算。
- 特殊赛道状态判断。
- 速度规划。
- 控制器。

## 关键难点

- 电机和电源噪声干扰。
- 电感安装高度和角度一致性。
- 高速时信号变化快。
- 特殊元素识别信息较少。
- 模拟电路问题和软件问题容易混淆。
