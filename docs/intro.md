# 项目介绍

全国大学生智能车竞赛资料分散在 GitHub、B 站、队伍博客、学校实验室页面、公众号文章和个人网盘中。这个项目希望把公开资料整理成一个可维护的知识地图，让后来者不必从零开始翻找。

## 这个站点解决什么问题

- 找资料：按年份、组别、技术主题快速定位资料。
- 看脉络：理解某一组别或某一年份的规则变化、主流方案和关键难点。
- 学方法：把算法、硬件、调试、工程管理等经验沉淀成知识库。
- 做贡献：用统一格式提交资源，降低维护成本。

## 信息架构

站点采用“三条主线 + 一个知识库”的结构。

| 模块 | 作用 | 适合查什么 |
| --- | --- | --- |
| 年份 | 以竞赛年份为线索 | 当年规则、赛题、获奖方案、公开视频 |
| 组别 | 以竞赛组别为线索 | 技术路线、常见硬件、开源项目、复盘经验 |
| 资源 | 以资料条目为线索 | GitHub 项目、B 站视频、博客、论文、工具 |
| 知识库 | 以通用主题为线索 | 控制、视觉、电磁、嵌入式、调试、仿真 |

## 页面设计原则

- 先入口，后细节：每个年份和组别页面先给概览，再给资源列表。
- 先结构，后数量：宁可少量高质量资料，也不堆砌不可维护的链接。
- 每条资源都要能被筛选：至少标注年份、组别、类型和关键词。
- 知识文章可复用：尽量把通用知识放到 `knowledge/`，不要散落在年份页面里。

## 适合谁使用

- 第一次参加智能车竞赛的学生。
- 正在选组、搭车、调车、找开源方案的队伍。
- 想复盘历年方案和技术演进的参赛者。
- 愿意整理公开资料、维护知识库的贡献者。

## 与官方资料的关系

本项目是社区资料导航，不代表赛事官方立场。规则、报名、赛程、奖项等信息应以官方渠道为准。站点中的资料仅作为学习与参考，使用开源代码时请遵守原作者许可协议。
