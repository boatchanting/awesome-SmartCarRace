# 资料收集路线图

本路线图用于规划资料收集优先级，帮助贡献者知道先整理什么。

## 第一阶段：建立骨架

- 完成 README、项目介绍、贡献说明。
- 建立年份、组别、知识库入口。
- 为主流组别创建占位页面。
- 统一资源条目格式。

## 第二阶段：补齐核心入口

- 整理近三年官方规则和赛题信息。
- 收集各组别高质量 GitHub 开源仓库。
- 收集 B 站上的规则解读、调车演示和赛后复盘。
- 标记资料对应年份、组别、类型和关键词。

## 第三阶段：沉淀知识库

- 补充控制算法、路径规划、视觉处理、电磁传感、嵌入式工程等基础文章。
- 将组别页面中的通用经验抽取到知识库。
- 增加调试流程、故障排查和工具链说明。

## 第四阶段：站点功能增强

- 引入静态站点生成器。
- 生成资源索引。
- 增加搜索与筛选。
- 增加失效链接检查。
- 增加贡献模板和 Issue 模板。

## 当前优先级

1. 近三年资料。
2. 摄像头组、电磁组、平衡组、AI 视觉相关资料。
3. 有 README、许可证和可复现说明的开源仓库。
4. 信息密度高、讲清楚调试过程的视频。
