# 知识库

知识库用于整理跨年份、跨组别可复用的智能车竞赛知识。这里不追求替代教材，而是把参赛中反复遇到的问题组织成可查、可链接、可持续更新的文章。

## 推荐阅读顺序

1. [新手入门](getting-started.md)
2. [传感器与硬件选型](hardware/sensors.md)
3. [控制与路径处理](software/control-and-path.md)
4. [调试与测试流程](tools/debugging.md)

## 主题规划

| 分类 | 内容方向 |
| --- | --- |
| 硬件 | 主控、电机、电调、舵机、电源、传感器、结构件 |
| 软件 | 嵌入式工程、驱动、状态机、日志、参数管理 |
| 算法 | PID、路径提取、速度规划、滤波、传感器融合 |
| 视觉 | 图像采集、二值化、边线提取、透视变换、AI 推理 |
| 电磁 | 电感排布、信号调理、赛道识别、抗干扰 |
| 调试 | 标定、日志、回放、故障排查、版本管理 |

## 写作建议

每篇知识文章尽量回答三个问题：

- 这个问题在什么场景下出现？
- 常见解决思路有哪些？
- 调试时如何判断方案是否有效？
