# 新手入门

智能车竞赛通常不是单一算法比赛，而是机械、硬件、嵌入式软件、控制算法、调试流程和团队协作的综合工程。

## 入门阶段先理解什么

- 规则决定目标：先读当年规则，再选技术路线。
- 组别决定传感器：摄像头、电磁、平衡、AI 视觉等组别的核心难点不同。
- 调试决定上限：能不能稳定复现问题，往往比单点算法更重要。
- 工程决定效率：代码结构、参数管理、日志和版本控制会直接影响迭代速度。

## 建议学习路径

1. 了解当年规则和目标组别。
2. 浏览同组别往年开源项目，先看整体架构。
3. 搭建最小可运行车模，让电机、舵机、传感器和主控跑通。
4. 加入基础控制闭环，完成低速稳定循迹。
5. 建立日志、参数和测试流程。
6. 再逐步提高速度、优化特殊元素处理。

## 常见误区

- 只看代码，不看机械和供电。
- 过早追求复杂算法，忽略基础稳定性。
- 没有记录参数变化，调试靠记忆。
- 所有逻辑写在一个大循环里，后期难以定位问题。
- 不区分训练视频、比赛录像、复盘文章和可复现代码。

## 最小资料清单

新队伍建议至少准备：

- 当年官方规则。
- 目标组别的往年优秀方案。
- 一个可编译的参考工程。
- 一份硬件连接表。
- 一份参数记录表。
- 一套调试日志或串口输出方案。
