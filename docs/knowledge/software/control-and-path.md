# 控制与路径处理

控制与路径处理是智能车软件中的核心环节。不同组别的输入不同，但最终都需要把感知结果转化为速度、方向或姿态控制指令。

## 基本链路

```text
传感器采集 -> 信号预处理 -> 路径或状态估计 -> 控制目标生成 -> 控制器输出 -> 执行机构
```

## 路径处理

常见任务：

- 提取赛道中心线或目标轨迹。
- 识别十字、环岛、坡道、障碍等特殊元素。
- 估计当前偏差、曲率和可信度。
- 根据赛道状态切换策略。

建议输出不要只给一个偏差值，最好同时保留：

- 路径可信度。
- 特殊元素状态。
- 近端和远端趋势。
- 原始数据摘要，便于调试。

## 控制器

常见控制方式包括 PID、串级控制、前馈控制和基于状态机的策略控制。

调试时建议先保证：

- 控制周期稳定。
- 方向和速度指令方向正确。
- 执行机构限幅明确。
- 参数调整可记录、可回退。

## 速度规划

速度不应只由全局固定值决定。更稳妥的做法是根据赛道状态动态调整：

- 直道提高速度。
- 弯道根据曲率降速。
- 特殊元素提前降速。
- 识别可信度降低时保守处理。

## 调试建议

- 先低速闭环，再逐步提速。
- 每次只调整少量参数。
- 保留失败数据，不只记录成功参数。
- 用日志对齐传感器输入、路径输出和控制输出。
