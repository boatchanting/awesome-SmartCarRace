# 传感器与硬件选型

传感器选型直接影响赛道感知能力、控制延迟和调试复杂度。不同组别的核心传感器不同，但选型思路可以复用。

## 选型维度

- 采样频率：是否满足车辆速度和控制周期。
- 信号质量：噪声、动态范围、抗干扰能力。
- 安装约束：高度、角度、重心、线束和机械强度。
- 软件支持：驱动成熟度、调试工具、数据可视化方式。
- 成本与备件：是否容易采购和快速替换。

## 摄像头

摄像头常用于识别赛道边线、元素、标志物或目标区域。

关注点：

- 分辨率与帧率的平衡。
- 曝光、增益和光照变化。
- 镜头视角与安装高度。
- 图像传输接口和处理延迟。
- 是否便于离线回放和调参。

## 电磁传感

电磁方案通常依赖电感阵列感知赛道电磁信号。

关注点：

- 电感数量、排布和安装高度。
- 模拟前端放大、滤波和保护。
- ADC 采样频率与同步方式。
- 线束布局和电机干扰。
- 标定方法和异常值处理。

## IMU 与编码器

IMU、编码器常用于姿态估计、速度估计和平衡控制。

关注点：

- 零偏和温漂。
- 采样周期稳定性。
- 与控制周期的时间对齐。
- 滤波延迟。
- 机械安装刚性。

## 记录建议

每次更换硬件或安装位置时，建议记录：

- 型号与版本。
- 安装位置和角度。
- 关键参数。
- 测试日期。
- 对稳定性和速度的影响。
