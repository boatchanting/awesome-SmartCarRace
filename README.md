# 全国大学生智能车竞赛开源资料导航

本项目计划建设一个面向“全国大学生智能车竞赛”的开源资料索引站点，长期收集并整理 GitHub 开源项目、B 站视频、竞赛相关知识、年份资料与组别经验。

目标不是替代官方通知或队伍文档，而是提供一个可搜索、可筛选、可持续维护的资料入口，帮助新队伍快速入门，也帮助有经验的队伍复盘、比较和沉淀方案。

## 项目定位

- 按年份整理竞赛规则、赛题变化、优秀方案、公开视频与复盘资料。
- 按组别整理常见技术路线、开源代码、机械结构、传感器配置与调试经验。
- 按知识主题整理算法、硬件、软件工程、仿真、调参、文档写作等基础内容。
- 为 GitHub Pages 网站提供清晰的信息架构、Markdown 内容源和后续搜索筛选基础。

## 资料收录范围

优先收录：

- 与智能车竞赛直接相关的 GitHub 仓库、Gitee 仓库、论文、博客、视频与课件。
- 具有明确年份、组别、学校或队伍背景的资料。
- 可复现、可学习、授权清晰、说明完整的开源项目。
- 公开演讲、经验分享、赛后复盘、规则解读和调试演示视频。

暂不优先收录：

- 无法判断来源或授权状态的压缩包、网盘合集。
- 只含营销导流、重复搬运或信息密度极低的内容。
- 与竞赛关系较弱、无法归类到年份、组别或知识主题的泛泛资料。

## 内容组织

```text
docs/
  intro.md                 项目介绍与使用方式
  contribution.md          贡献说明与资料提交规范
  roadmaps/                站点规划、信息架构和采集路线
  years/                   按竞赛年份组织的入口页
  groups/                  按竞赛组别组织的入口页
  knowledge/               可复用知识库
```

每条资源建议保留这些字段：标题、链接、类型、年份、组别、关键词、简介、推荐理由、维护状态、授权说明。

## 后续网站能力

计划支持：

- Markdown 驱动的 GitHub Pages 静态站点。
- 基于年份、组别、资源类型、关键词的筛选。
- 本地或前端索引搜索。
- 资源卡片、知识文章、路线图和贡献模板。
- 失效链接巡检与资料质量分级。

## 参与贡献

欢迎提交资料链接、修正文档、补充组别页面、整理年份页面或增加知识文章。提交前请先阅读 [贡献说明](docs/contribution.md)。
