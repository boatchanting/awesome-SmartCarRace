## ✨ 项目简介

**全国大学生智能车竞赛开源资料导航** 是一个面向智能车竞赛生态的 Awesome 风格资料入口。项目目标不是替代官方通知或队伍内部文档，而是帮助参赛者更快找到可信、可复用、可学习的公开资料。

它适合：

- 🧑‍🎓 刚接触智能车竞赛的新手
- 🏁 正在备赛的参赛队员
- 🧑‍💻 队长与技术负责人
- 👨‍🏫 指导老师
- 🧭 往届参赛选手与资料贡献者

## 🧱 项目结构

```text
.
├── index.html                    # GitHub Pages 单页入口
├── main.js                       # 文档加载、搜索、资源筛选与首页渲染逻辑
├── style.css                     # 站点样式与响应式布局
├── sw.js                         # PWA 缓存策略
├── data/
│   ├── taxonomy.json             # 年份、组别、类型、主题等枚举
│   ├── resources.index.json      # 资源分片索引
│   └── resources/
│       └── {year}/{group}/
│           └── resources.json    # 按年份和组别拆分的资源数据
├── docs/
│   ├── intro.md                  # 项目介绍
│   ├── contribution.md           # 贡献说明
│   ├── commit-message.md         # Git 提交规范
│   ├── years/                    # 历届竞赛资料入口
│   ├── groups/                   # 竞赛组别资料入口
│   ├── knowledge/                # 可复用技术知识库
│   └── roadmaps/                 # 站点规划与信息架构
├── schemas/                      # 资源、分类、索引 JSON Schema
└── scripts/
    ├── generate-docs-manifest.js # 生成文档清单
    ├── validate-resources.js     # 校验资源数据
    └── import-resource-drafts.js # 导入前端导出的资源草稿
```

## 🧩 资源数据维护

资源数据按下面的路径拆分：

```text
data/resources/{年份}/{组别}/resources.json
```

新增资源分片后，需要把文件路径加入：

```text
data/resources.index.json
```

也可以在网站“资源”页面使用“添加资源”表单先录入资料。页面会把新增内容保存在当前浏览器，点击“导出 JSON”后，可用下面的命令合并到对应资源分片：

```bash
node scripts/import-resource-drafts.js resources-drafts-YYYY-MM-DD.json
node scripts/validate-resources.js
```

## ✅ 资料收录标准

优先收录：

- 与智能车竞赛直接相关的 GitHub / Gitee 仓库
- B 站公开视频、调试演示、规则解读、经验分享
- 技术报告、赛后复盘、博客教程、论文资料
- 具有明确年份、组别、学校或队伍背景的资料
- 可复现、可学习、授权清晰、说明完整的开源项目

暂不优先收录：

- 无法判断来源或授权状态的压缩包、网盘合集
- 只含营销导流、重复搬运或信息密度极低的内容
- 与竞赛关系较弱、无法归类到年份、组别或知识主题的泛泛资料
